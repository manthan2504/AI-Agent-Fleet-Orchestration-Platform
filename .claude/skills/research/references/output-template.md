# Research Output Template

Copy this shape for every research result.

**Research Question**
The exact question investigated.

**Context**
Why it matters to the current task or decision.

**Findings**
The key factual findings, plainly stated. No hedging where the evidence is solid; clear hedging where it isn't.

**Current Practice**
The relevant current pattern or approach, with a note on how fast this specific area moves (some things are stable for years, some go stale in months — say which this is).

**Alternatives**
Meaningful alternatives, when applicable. Skip this section if there genuinely isn't a reasonable alternative — don't manufacture one.

**Trade-offs**
The real advantages, disadvantages, and risks of each option under consideration.

**Recommendation**
A reasoned call, when the evidence supports one. If it doesn't, say that instead of forcing a recommendation to fill the section.

**Confidence**
High / Medium / Low — and *why*: source quality, currency, agreement across sources.

**Impact on Project**
What this implies for the existing architecture, plan, or code — if anything. "No impact" is a valid answer.

**Sources**
The sources that actually mattered to the conclusion, with links. Not every page visited — the ones that changed the answer.
